# Screenshots

Captures auto-générées par `scripts/screenshots.mjs`.

**Procédure** :

```bash
npx playwright install chromium   # une seule fois
npm run dev                       # terminal 1
node scripts/screenshots.mjs      # terminal 2
```

Voir [`docs/MARKETING-ASSETS.md`](../../docs/MARKETING-ASSETS.md) pour la liste complète, les URLs Vercel pour embed direct, et les tips capture qualité.

> ⚠️ Les `.png` ne sont **pas** committés (volumineux). Le `.gitignore` les filtre. Régénère-les avant chaque ship session.
